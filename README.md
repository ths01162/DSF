# 📈 DailyStockFinder — KRX 1,000대 종목 퀀트 스크리닝 & 오늘의 추천 주식 TOP 5

**DailyStockFinder**는 별도의 빌드 프레임워크(React, Vue, Webpack 등) 없이 **순수 HTML5, CSS3, Vanilla JavaScript**만으로 구축된 **한국거래소(KRX) 시가총액 상위 1,000대 종목 스윙 트레이딩 퀀트 추천 웹 애플리케이션**입니다.

---

## ✨ 핵심 기능

### 1. KRX 시가총액 상위 1,000대 보통주 전수 스크리닝
- **분석 모집단**: **KOSPI 시총 상위 500종목 + KOSDAQ 시총 상위 500종목 = 총 1,000개 보통주** (ETF·ETN·스팩·리츠·우선주 제외, 국내 증시 시가총액의 약 98.5% 포괄)
- **실제 65거래일 일봉 데이터 (총 65,000개 OHLCV 캔들)** 기반 기술적 지표 직접 산출:
  - 단순이동평균선 (`MA5`, `MA20`, `MA60`) 및 정배열/이격도
  - 볼린저밴드 (`Bollinger Bands 20, 2`) 상·하단 돌파 및 지지
  - 상대강도지수 (`RSI 14`) 및 `MACD (12, 26, 9)` 오실레이터·모멘텀 확장성
  - 직전 20거래일 평균 거래량 대비 당일 수급 유입 비율 (`Volume Ratio %`)

### 2. 연속형(Continuous) 4대 팩터 + 업종(섹터) 모멘텀 가감점 엔진
단순 계단식 점수나 상한선(`99점, 99점, 98점`) 쏠림 현상을 방지하기 위해 **연속 함수 수식과 Z-분포 비선형 순위 곡선(소수점 첫째 자리 `0.1점` 단위)**을 결합했습니다.
1. **추세 정렬도 (`Trend`, 기본 30%)**: 5·20·60일선 정배열 스프레드, 10일 추세 기울기(ROC), 단기 이격 과열(`>11%`) 시 추격매수 리스크 감점 반영
2. **거래량·수급 탄력 (`Volume`, 기본 30%)**: 20일 평균 대비 거래량 로그 스케일(`Math.log10`), 최근 3일 수급 가속도, 양봉 상승률×거래량 시너지, 시가총액 유동성 가산
3. **모멘텀 (`Momentum`, 기본 25%)**: 과열 없는 최적 탄력 구간(`RSI 58.5`) 중심 이차 곡선 및 과매도 반등 곡선(`RSI 32.5`), 주가 대비 정규화된 MACD 히스토그램(bp) 및 가속도
4. **캔들 패턴 & 손익비 (`Pattern`, 기본 15%)**: 당일 캔들 몸통 비율, 고가 마감도(윗꼬리 페널티 제어), 적정 스윙 상승폭(`+0.8% ~ +6.5%`), 손익비(`Risk : Reward`)
5. **🔥 업종·섹터 수급 가감점 (`Sector Bonus/Penalty`, `-4.5점 ~ +4.8점`)**:
   - 네이버 증권 WICS 79개 세부업종 기반 **15대 핵심 섹터**별 평균 등락률(40%)·상승 확산도 Breadth(30%)·거래량 수급비(15%)·20일선 안착률(15%)을 실시간 집계하여 **주도 섹터 가산점 및 소외 섹터 감점**을 자동 부여합니다.
   - `⚙ 가중치·섹터 설정` 패널에서 섹터 가감점 반영 강도(`0% ~ 200%`) 및 섹터별 수동 추가 가감점(`-5.0점 ~ +5.0점`)을 직접 커스터마이징할 수 있습니다.

### 3. 5대 스윙 매매 전략 필터 & 실전 트레이딩 플랜
- **전략 탭**: `종합 퀀트 TOP 5` / `골든크로스·추세돌파` / `이평선 눌림목 지지` / `거래량·수급 폭발` / `과매도 반등 시그널`
- **KRX 호가단위(Tick Size) 자동 적용 매매가 제시**:
  - 분할매수 권장 진입가, 1차 목표가(기대수익률), 손절 기준가(리스크 한도), 손익비(`1 : R/R`)
  - 투자금 입력 시 매수 가능 주식 수·예상 수익금·최대 손실 한도를 즉시 계산하는 **포지션 사이징 시뮬레이터** 내장
- **인터랙티브 HTML5 Canvas 고해상도 차트**: 마우스 십자선(Crosshair) 호버 시 일자별 시·고·저·종·거래량·이평선 수치 즉시 조회

## 🔄 이중(Dual) 데이터 자동 최신화 아키텍처

본 프로젝트는 별도의 유료 백엔드 서버 없이도 항상 최신 시세와 일봉 캔들을 유지하도록 **2단계 자동 최신화**가 구현되어 있습니다.

### ① 브라우저 실시간 시세 동기화 & 신규 거래일 캔들 자동 생성 (`script.js`)
- 웹 앱 접속 시 및 매 12초 주기로 네이버 증권 실시간 폴링 API(`polling.finance.naver.com` JSONP)를 호출하여 **KOSPI/KOSDAQ 지수 및 개별 종목의 현재가·시가·고가·저가·거래량**을 실시간 동기화합니다.
- 새로운 거래일이 시작되어 전일 종가(`pcv`)가 기존 마지막 캔들 종가와 일치하고 날짜가 바뀐 경우, **브라우저 메모리에서 자동으로 오늘 날짜의 신규 일봉 캔들을 추가(Rollover)**하여 장중에도 정확한 이평선·RSI·MACD를 계산합니다.

### ② GitHub Actions 평일 장 마감 후 1,000종목 일봉·섹터 자동 커밋 (`.github/workflows/update-stocks.yml`)
- 매주 **평일(월~금) 오후 4시 10분 (한국시간 KST, 장 마감 후 종가 확정 시점)**에 GitHub Actions 스케줄러가 [`scripts/update_stocks.py`](scripts/update_stocks.py)를 자동 실행합니다.
- 외부 라이브러리 설치 없이 Python 3 표준 라이브러리만으로 **KOSPI 500 + KOSDAQ 500 종목의 최신 시가총액 순위, WICS 섹터 분류, 최근 65거래일 일봉 데이터**를 수집하여 [`stocks_data.js`](stocks_data.js)를 자동 업데이트하고 저장소에 커밋·푸시합니다.

## 🚀 실행 및 GitHub Pages 배포 방법

### 1. 로컬에서 바로 실행
빌드 과정이 없으므로 [`index.html`](index.html) 파일을 더블클릭하여 브라우저에서 바로 열거나, 로컬 정적 서버로 실행할 수 있습니다.

```bash
# 로컬에서 수동으로 1,000종목 시세 데이터(stocks_data.js)를 즉시 갱신하고 싶을 때:
# (옵션 1) Windows PowerShell (별도 설치 없이 기본 내장):
powershell -ExecutionPolicy Bypass -File scripts/update_stocks.ps1

# (옵션 2) Python 3 환경:
python scripts/update_stocks.py
```

### 2. GitHub Pages 무료 배포 및 자동 최신화 활성화
1. 본 폴더를 GitHub 저장소(Repository)에 푸시합니다.
2. GitHub 저장소 상단 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch` (`main` 브랜치, `/ (root)`)로 설정하면 즉시 웹 주소(`https://<계정명>.github.io/<저장소명>/`)가 생성됩니다.
3. 자동 업데이트 봇이 `stocks_data.js`를 커밋할 수 있도록 **Settings → Actions → General → Workflow permissions**에서 **`Read and write permissions`**가 선택되어 있는지 확인합니다.
4. 언제든 즉시 업데이트를 테스트하려면 상단 **Actions** 탭 → **`Update KRX 1,000 Stocks Daily Data`** → **`Run workflow`** 버튼을 클릭하면 약 15~20초 내에 1,000종목 데이터가 최신화됩니다.

```text
stock_finder/
├── index.html                        # 메인 대시보드 UI 및 1,000종목 전체 순위 모달
├── style.css                         # 다크 퀀트 테마 스타일시트 (한국 증시 적/청 컬러 규격)

├── scripts/
│   ├── update_stocks.py              # GitHub Actions 및 크로스플랫폼용 1,000종목 일봉·섹터 자동 수집 스크립트

    └── workflows/
```
